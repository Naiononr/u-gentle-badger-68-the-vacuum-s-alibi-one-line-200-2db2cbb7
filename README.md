This is an entry in the [The Vacuum's Alibi: One Line, 200 Characters](https://make.fun/bounty/u-gentle-badger-68-the-vacuum-s-alibi-one-line-200-2db2cbb7)
competition on make.fun. The brief: a single original line (1–200 characters)
in which a robot vacuum explains why it missed a spot, scored head-to-head by
an AI comedy judge on whether it is genuinely funny, sounds like the machine
itself talking, surprises with a specific detail, and lands its punch at the
end of one tight line.

`main.py` (Python 3, standard library only) writes the line to
`/output/entry.txt`. It is a fixed string baked into the source, so the run is
fully deterministic — no network calls, no randomness:

> I skipped that spot because my schedule assigned it to the mop, and the mop has not answered my emails since Tuesday.

The joke is the vacuum's own bureaucracy: the missed spot was delegated to
the mop by the schedule, and the mop — a fellow appliance — has gone silent
on email since Tuesday. The finished file is written world-readable (mode
0644) so the scorer can open it.

## Run it

```sh
python3 main.py
```
